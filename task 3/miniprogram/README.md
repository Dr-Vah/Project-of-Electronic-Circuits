# OmniRemoteBLE — 遥控小车微信小程序

配套 [RemoteControl](../RemoteControl/) 固件的微信小程序，作为遥控驾驶舱：通过 BLE 控制小车行驶，连接小车热点后可观看摄像头第一视角画面，并可选择「奶蛙」表情。相比网页方案，小程序直接用原生传感器接口实现体感控制，无需 HTTPS 证书信任，开箱即用。

## 功能特性

- **BLE 遥控**：扫描并连接 `Omni-Remote-BLE`，发送驾驶指令。
- **驾驶方式**：
  - 摇杆模式：触摸拖动控制前后左右平移。
  - 体感模式：手机平放（屏幕朝上、头朝前）倾斜控制，左右倾斜横移、前后倾斜进退。
- **速度控制**：低 / 中 / 高三档限速。
- **转向**：独立的左转 / 右转按钮。
- **第一视角画面**：连接小车热点 `Omni-Remote` 后，通过 TCP `192.168.4.1:8266` 拉取 MJPEG 视频帧。
- **表情选择**：选择「奶蛙」自动情绪或手动表情。

## 运行

1. 用微信开发者工具打开 `miniprogram/` 目录。
2. 在 `project.config.json` 中确认 `appid`（当前为 `wx426122b1f5ce2b18`），或用你自己的 AppID 替换。
3. 真机调试需在微信公众平台注册并绑定开发者身份；仅预览可用「预览」扫码。

## 使用说明

1. 手机打开小程序，点击「连接」扫描并连接小车 BLE `Omni-Remote-BLE`。
2. 选择摇杆或体感模式驾驶，调节速度档位。
3. 点击「连 WiFi」连接小车热点 `Omni-Remote`（密码 `omni2026`），再点击「开启画面」观看摄像头视频。
4. 在表情区选择奶蛙表情。

> 注意：Android 上观看画面前，需保证定位权限已授权（用于获取 WiFi BSSID 绑定 socket），并避免手机把流量切到蜂窝数据导致连不上 `192.168.4.1`。
