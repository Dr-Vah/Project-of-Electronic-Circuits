# 奶蛙驾驶舱：同一个小程序完成遥控、视频与表情

## 当前体感操作（点击开关）

按用户要求，体感改为点击“校准当前握姿并开始”，无需持续按住。点击时记录基础握姿及可用的罗盘朝向；回到零点姿态输出零速度，但体感保持开启。再次点击或“立即停止”解除体感，下次开始重新校准。左右旋转按钮仍需按住，松开按钮后恢复当前体感输入。换模式、换档、切换表情、断联、切后台、传感器失效或观看中的画面失效均会解除体感，不会自动续跑。罗盘不可用时可仅用倾斜平移，按钮旋转。下文旧版“按住体感”的描述以本段为准。

## 2026-09-09 摄像头启动重启修复

用户实机日志显示 Wi-Fi AP/DHCP 已启动，但 UVC 的 USB 传输内存分配失败后发生重复释放，触发 `tlsf_free` 断言并循环重启。这会让手机看不到稳定的热点，不是 Wi-Fi 密码问题。

已将本地 UVC 组件的传输资源清理改为可重复调用；USB 传输缓冲由 3 × 10 KiB 降为 3 × 2 KiB，并启用 `CONFIG_BT_ALLOCATION_FROM_SPIRAM_FIRST=y`。16 MiB PSRAM 不能直接代替本芯片 USB 所需的内部 DMA 缓冲，减少和腾出内部内存才有效。启动日志新增请求摄像头格式、内部 DMA 空闲总量与最大连续块，便于实测确认。

运行 `python tests/test_uvc_cleanup.py` 可对实际驱动中的分配／释放函数注入数组和每个 USB 传输的分配失败，验证 BULK／ISOC 清理不会重复释放。需要重新 build/flash；旧配置也必须启用上述蓝牙 PSRAM 选项，本地 sdkconfig 已更新。修复后的实车运行仍待用户复测。

本版在 `RemoteControl` 工程中集成微信小程序入口。手机同时连接小车蓝牙和 Wi-Fi 后，可以在同一个页面看摄像头、体感／摇杆驾驶、查看奶蛙状态和切换表情。无需打开浏览器或安装 HTTPS 证书。

## 现在有哪些功能

| 功能 | 小程序里的操作 |
| --- | --- |
| 第一视角 | 开启／暂停画面，180° 翻转；默认与原网页相同，旋转 180° |
| 体感平移 | 按住驾驶，每次按下校准零点；手机前后、左右倾斜控制平移 |
| 体感旋转 | 相对按下时的罗盘朝向，水平转动手机控制自转 |
| 备用摇杆 | 切换“触屏摇杆”，按住拖动；没有传感器也可用 |
| 旋转按钮 | 按住左／右转，可与摇杆同时操作，也可覆盖体感的罗盘旋转 |
| 限速 | 低 50%、中 75%、高 100%；换档先停车 |
| 奶蛙状态 | 每 500 ms 从小车同步表情、眩晕和疲劳；过期状态显示“未更新” |
| 表情选择 | 自动情绪及原有 12 款表情，实际作用于车载屏幕；选择时先停车 |
| 停车 | 立即停止；体感松手停止所有运动；摇杆与旋转各自松手归零，最后一个触点松开撤销驾驶权 |
| 异常处理 | 固件 300 ms 指令超时撤销驾驶权；传感器异常停止体感；切后台断开并停车；观看中的画面中断／过期也解除驾驶 |

平移最高 0.12 m/s，旋转最高 0.60 rad/s，沿用本车电机引脚、PID、轮参数和速度缓变。眩晕／疲劳是表情状态，不是电池电量。

## 第一次使用

1. 在 `RemoteControl` 目录运行 `./build.ps1`。然后在 ESP-IDF 终端运行 `idf.py -p 实际串口 flash`，**完整烧录，包括分区表**。本版应用分区为 1984 KiB，适配当前 2 MiB Flash，NVS 和 PHY 地址保持不变；不要只写应用 bin，无需擦除整片 Flash。
2. 微信开发者工具导入本目录下的 `miniprogram`。`project.config.json` 使用 `touristappid` 占位，真机预览前换成你有权限的 AppID。需要能使用 TCP API 的微信／基础库（TCP 最低 2.18.0，建议使用开发工具提供的稳定新版）。
3. 首次扫码预览时先保持手机互联网正常，进入小程序后再连接小车。开启手机蓝牙，点击“连接小车”，搜索 `Omni-Remote-BLE`。
4. 点击“连接画面 Wi-Fi”，连接 `Omni-Remote`，密码 `omni2026`。系统提示无互联网时保持连接；iPhone 如提示本地网络访问需允许。自动连接失败时，页面会提示手动连接。**从系统设置返回会因切后台保护而断开蓝牙，需要重新点连接小车。**
5. 点击“开启画面”。摄像头正确连接并提供 MJPEG 时会显示实时图像；未就绪时显示明确提示，不把旧图伪装成实时画面。
6. 默认低速，先架空车轮检查方向。体感时竖屏、屏幕朝上握持，等待传感器就绪再按住驾驶；需要目视驾驶可暂停视频。摇杆模式无需加速度计或罗盘。
7. 奶蛙卡片显示实际状态，表情选择器可切回自动情绪或选原有 12 种表情。

初次授权、Wi-Fi 设置和切后台都会影响当前操作。应用不会在回到前台、恢复画面或收到迟到指令后自动续跑，需要重新按住。

## 与原网页的关系

原网页源码和入口保留：`http://192.168.4.1/` 用于摇杆、视频和表情，原网页体感仍需可信 HTTPS。**本次没有把旧网页体感报错称为已修复；完整小程序是替代入口。**

小程序驾驶、表情、状态走 BLE；视频走同一手机到小车热点的局域网 TCP。两条链路在同一页面并行工作。仅需驾驶／表情时不必连接 Wi-Fi。

网页与小程序共用一个驾驶令牌，不能同时抢控。任一 STOP 都能停车；BLE 断开只释放自己的驾驶权。保留原来的 Wi-Fi 离线保守规则：任一热点设备掉线也会停车，包括当时由 BLE 控制的情况。

## 视频为什么能放进小程序

微信官方 [createTCPSocket 文档](https://developers.weixin.qq.com/miniprogram/dev/api/network/tcp/wx.createTCPSocket.html) 允许连接同一局域网的非本机 IP，并限制部分端口。固件新增 `192.168.4.1:8266`，没有把原来的 HTTP 81 或 HTTPS 8443 端口直接套进 TCP API。官方 [connect 文档](https://developers.weixin.qq.com/miniprogram/dev/api/network/tcp/TCPSocket.connect.html) 中连接超时按秒设置。

Android 支持时使用 `TCPSocket.bindWifi` 绑定当前 Wi-Fi，传入由 `getConnectedWifi` 获取的 BSSID，避免无互联网热点的路由问题。无法读取 Wi-Fi 信息时尝试正常局域网路由；连接失败会提示检查 Wi-Fi／权限，不依赖开发工具的“关闭域名校验”开关。

视频为连续 JPEG 预览，最多约 4 fps，不是高清视频编码直播，也不含声音。独立低优先级任务、一个观看端，额外 128 KiB PSRAM 快照；网络发送不持有电机锁或摄像头帧锁。固件不发送超过 1 秒的旧帧，小程序也检查帧年龄、接收与解码耗时。画面失效隐藏旧图并解除当前驾驶，恢复后不自动续跑。

小程序处理 TCP 任意拆包，单帧上限 128 KiB，写入有限数量的本地临时图片后显示，及时清理上一帧；不不断创建新连接。连接失败需要手动重试，并限制重试次数，避免超过微信每 5 分钟 20 个 TCP 实例的限制。

## 协议与来源

体感／BLE 初始思路来自队友 [BLEControl dev 2b072bb](https://github.com/Dr-Vah/Project-of-Electronic-Circuits/tree/2b072bb/BLEControl)。修正了原 UUID 数组与注释不一致的问题，使用严格的服务发现和输入校验，没有复用队友的 AppID。

- 广播：`Omni-Remote-BLE`；服务：`6E400001-B5A3-F393-E0A9-E50E24DCCA9E`。
- 带响应写：`6E400002-B5A3-F393-E0A9-E50E24DCCA9E`。`#ARM!` 申请驾驶权，`#vx,vy,w!` 发送 m/s、m/s、rad/s，`#STOP!` 停车，`#FACE:-1!` 自动表情，`#FACE:0!` 到 `#FACE:11!` 手动表情。
- 状态读取／通知：`6E400003-B5A3-F393-E0A9-E50E24DCCA9E`，8 字节：版本 1、眩晕、疲劳、闲置秒（最大 255）、表情 ID、手动 ID+1、停车故障、BLE 持有驾驶权。状态通知和表情修改都不刷新驾驶看门狗。
- 每次最多一个控制写入，220 ms 写入超时后关闭 BLE。松手优先排入 STOP，旧回调不能恢复驾驶。
- TCP 请求为单字节 `1`。响应头 20 字节：`OVF1`、JPEG 长度、帧序号、帧年龄 ms、状态码，后四项均为 little-endian uint32。状态 0 后跟 JPEG；状态 1 表示没有新鲜画面，长度为 0。
- 坐标：底盘 +x 右、+y 红外方向为前、正旋转逆时针。小程序加速度 Y 和罗盘顺时针偏差取反。体感相对死区 0.15 g／8°，0.7 g／45° 满输入，平移向量归一化。方向和握持方式仍需真机核对。

BLE 沿用未配对方案，附近能连接的设备可以尝试申请驾驶权，Wi-Fi 密码不保护 BLE。TCP 视频仅绑定小车 AP 地址，不修改互联网服务或系统信任设置。
