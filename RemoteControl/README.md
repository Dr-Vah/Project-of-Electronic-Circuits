# 手机倾斜遥控 + 第一视角 + 奶蛙情绪 V5

独立 ESP-IDF 5.4.4 / ESP32-S3 工程。安卓 Chrome 和 iPhone Safari 使用同一个触屏控制页。
这一版实现手机倾斜控制、备用摇杆、按钮旋转、三档限速、断联停车、TFT Emoji、第一视角 JPEG 预览和情绪值。没有自主驾驶。
页面内嵌于固件，不访问互联网，不需要电脑转发或安装 App。

## 连接与操作

1. 烧录本工程，复位小车。
2. 手机连接 Wi-Fi **Omni-Remote**，密码 **omni2026**。系统提示无互联网时选择保持连接。
3. 在完整浏览器打开 **http://192.168.4.1/**（不是 HTTPS，也不要用 Wi-Fi 登录小窗口）。
4. 默认低速。按住圆盘并拖动控制前后、左右平移；松开圆盘停止平移。
5. 按住左转或右转按钮控制旋转，可用另一根手指同时操作圆盘。
6. 松开全部控制或点击“立即停止”停车。断联后必须松开并重新按下，不会自动续跑。

前方沿用原工程：红外模块朝向为 +y；+x 是车身右侧；正角速度为逆时针。
手机摇杆方向以车身为参考，不随手机朝向改变。初次实车验证应架空车轮，核对三个轮子的方向，然后低速落地测试。
本版本不启用超声避障，驾驶者判断周围障碍。

## 构建与烧录

V5 更新后需要重新 build / flash，手机重新打开页面即可看到“手机体感 · 奶蛙 V5”。
奶蛙素材扩大了固件体积，应用分区从 1 MiB 改为 1500 KiB（仍适配当前 2 MiB Flash 配置）。
本次须使用 `idf.py -p 实际串口 flash` 完整烧录，包含新分区表，不能只更新应用 bin。
NVS 与 PHY 分区位置保持一致，无须 erase-flash。无需重新生成已有手机证书。

## 手机倾斜控制：首次设置

仍然直接连接小车的 Omni-Remote 热点，不需要电脑转发。网页姿态接口要求可信 HTTPS，iPhone 还需要点击触发运动与方向授权。跳过浏览器证书错误并不等同于可信页面。
参考：[MDN 姿态接口](https://developer.mozilla.org/en-US/docs/Web/API/DeviceOrientationEvent)。

本工程已生成专属本地 CA 和服务器证书，固件内嵌 HTTPS 所需证书及服务器密钥。安装到手机的只应是 **omni-root.cer 公共证书**，不要分享私钥。

1. 烧录 V5，连接原热点，先打开 **http://192.168.4.1/**。
2. 展开“首次使用体感：证书与连接”，下载小车证书，或直接打开 **http://192.168.4.1/omni-root.cer**。
3. 按以下手机步骤安装并信任，然后打开 **https://192.168.4.1/**。必须没有证书错误。

### iPhone

- Safari 下载证书后，到 **设置 → 通用 → VPN 与设备管理**，找到下载的 Omni Remote Local CA 描述文件并安装。
- 再到 **设置 → 通用 → 关于本机 → 证书信任设置**，开启该根证书的完全信任。
- 回到 Safari 打开 HTTPS 地址，点击“启用手机倾斜”，允许运动与方向访问。

参考：[Apple 手动证书信任说明](https://support.apple.com/en-us/102390)。仅安装描述文件而没有开启完全信任时，HTTPS 体感仍可能不可用。

### 安卓

- 下载证书后，在系统设置搜索“安装证书”，选择 **CA 证书**，导入 omni-root.cer。
- 常见路径：**安全与隐私 → 更多安全设置 → 加密与凭据 → 安装证书 → CA 证书**；不同品牌名称会有差异。
- 使用 Chrome 打开 HTTPS 地址，点击“启用手机倾斜”。如浏览器提示访问运动传感器，请允许。

参考：[Google 证书安装说明](https://support.google.com/pixelphone/answer/2844832)。请勿把 CA 证书误装为 Wi-Fi 客户端证书。

## 体感驾驶操作

1. 手机竖屏、屏幕朝上，保持略微倾斜的舒适握姿；不需要完全水平，避免接近竖直或翻面。
2. 点击“启用手机倾斜”，确认出现实时角度读数。
3. **按住“驾驶”按钮**，按下瞬间记录当前姿态作为零点。
4. 从该姿态向前倾控制前进、向后倾控制后退，向左/右倾控制横移。倾斜越大速度越快；原三档限速仍生效。
5. 另一根手指可同时按住左右旋转按钮。**松开体感驾驶按钮会停止全部运动，包括旋转**。
6. 每次重新按住都会重新校准。点击“触屏摇杆”会先停车，再回到原操作方式。

默认每轴 5° 死区，偏离 25° 到达该档最高速度，斜向输入归一化，使用约 80 ms 时间常数滤波。屏幕横竖方向用于坐标变换，但切换屏幕方向时必须松手重新校准。
无效姿态、前后/左右绝对倾角超过 75°、姿态事件超过 300 ms 未更新时，页面停止并解除驾驶状态，恢复传感器也不会自动续跑。小车原有独立 300 ms 指令超时保护继续生效。
体感不依赖摄像头，即使视频关闭仍可操作。普通 HTTP 页面仍可用摇杆，但会拒绝进入体感模式。

## HTTPS 与证书维护

- HTTPS 控制使用 443；HTTPS 视频使用独立端口 8443。HTTP 80/81 保留，HTTPS 页面不会请求明文视频。
- 固件新增 HTTPS 会增加内存和握手开销，首次打开页面与视频应先等待连接完成，再开始驾驶。HTTP 与 HTTPS 共用同一份驾驶令牌，不能同时抢控。
- 根证书有效期 10 年，服务器证书 365 天。续期执行 `python setup_tls.py`，然后重新 build / flash；复用根证书时手机不需要重新安装。手机时间必须正确。
- 私钥在 `.tls/root-key.pem` 与 `main/tls/server-key.pem`，已加入忽略规则；不要上传或传给他人。生成脚本不会修改电脑或手机的信任设置。
- 新电脑构建前运行 `python setup_tls.py`；若要沿用手机已经信任的证书，请保留整套本地证书文件。更换 CA 后手机需要重新安装信任；项目结束可在手机设置删除该 CA。

## 第一视角画面

1. 沿用原 UVC 摄像头接线：USB D− 接 GPIO19，D+ 接 GPIO20，摄像头接合适的 5V 电源并共地。下载仍通过 CP210x/UART，勿把同一 USB-OTG 接口同时连接电脑与摄像头。
2. 手机连接原热点并打开原地址，点击页面顶部“开启画面”。无需电脑转发。
3. 默认画面旋转 180°，与原摄像头安装习惯一致；若倒置，点击“翻转画面 180°”。此按钮只改图像，不改变车身控制方向。
4. 点击“暂停画面”关闭预览。切后台或锁屏会暂停，需要重新点击开启。

优先采用摄像头支持的最小 MJPEG 分辨率和最慢帧率，固件最多发布约 5 fps；HTTP 视频服务所有客户端合计限流约 5 fps，建议只开一台手机的视频。实际帧率、画质和网络延迟需实车测量。
直接转发压缩 JPEG，不解码或推理；上限每帧 128 KiB，超大帧会被丢弃。视频使用独立低优先级任务（HTTP 81 或 HTTPS 8443），控制使用 HTTP 80 或 HTTPS 443。JPEG 缓冲使用 PSRAM，网络发送不持有驾驶锁或相机帧锁。两个视频任务以独立发送锁保护共享快照，忙时丢请求而不覆盖正在发送的图像。
手机显示的“本次接收 ms”是请求到图像解码完成的耗时，不是精确端到端相机延迟。固件拒绝超过 1 秒的旧帧，页面也检查帧年龄与接收耗时；失败时隐藏旧图并显示重试提示。视频异常本身不改变驾驶指令，请转为目视操作；原驾驶指令超时仍自动停车。
摄像头没接、没有 MJPEG 模式或 PSRAM 不可用时，遥控与 Emoji 可继续使用。相机启动失败后可重新插拔摄像头；USB 服务初始化失败需要复位。屏幕仍显示表情，视频只显示在手机上。

## 情绪规则

情绪仅影响表情，不改变电机速度；疲劳不是电池电量。

| 状态量 | 规则 |
| --- | --- |
| 眩晕 0～100 | 有旋转指令时按旋转力度积累，满力度每秒 +30；停止旋转每秒 −12 |
| 眩晕表情 | 达到 60 时触发，降到 25 才解除，避免来回闪烁；默认低速持续转圈约 4 秒触发 |
| 疲劳 0～100 | 有移动或旋转指令时每秒 +2，停车每秒 −4；达到 75 显示打哈欠 |
| 闲置睡眠 | 连续 5 秒无运动指令后左右张望，15 秒后入睡，再次驾驶唤醒（疲劳过高仍打哈欠） |
| 其他自动表情 | 正常驾驶显示墨镜开车，刚停车显示开心；大笑、抱心、惊讶、鼓腮、点赞可手动选择 |

优先级：断联提示 > 手动固定表情 > 眩晕 > 疲劳哈欠 > 闲置睡眠 > 闲置张望 > 驾驶/开心。手动表情期间情绪仍计算，选“自动情绪”即可恢复联动。重启后情绪清零。
手机闲置时每 500 ms 读取情绪状态，按住驾驶时暂停额外状态轮询以减少通信竞争；屏幕上的情绪仍持续更新。读取状态和视频都不会续期驾驶令牌。

## 奶蛙屏幕

默认自动模式按上表情绪规则变化。手机页面下方的“奶蛙表情”可选择自动情绪或 12 款手动表情。
包括呼呼睡、开心、酷酷开车、抱心、转晕了、委屈掉线、左右张望、捧腹大笑、累到哈欠、吓一跳、气鼓鼓、得意点赞。
每款 2 帧，共 24 帧；睡眠每帧 1100 ms，眩晕/大笑 350 ms，其他 650 ms。
原始图集及小屏动画预览在 `assets/naiwa/`，素材来源和生成提示词同目录保存。
图片以 256 色 RGB565 + RLE 存入 Flash，总计约 281 KiB；低优先级显示任务直接写入既有帧缓冲，不分配新的大块 RAM。

断联或驾驶指令超时会优先显示奶蛙拿着掉线插头的委屈表情，重新按住控制并成功取得驾驶权后解除；手动表情不能覆盖断联提示。
屏幕底部青色条表示有手机接入且没有控制超时，粉红色条表示未连接或断联保护。它不代表网络延迟或电量。
表情选择不会让车运动，也不刷新 300 ms 驾驶看门狗。另一台手机正在驾驶时，仅当前驾驶端可改表情。

沿用原来的 ST7735S 128×160 接线：

| TFT 接口 | ESP32-S3 |
| --- | --- |
| VCC / GND | 3V3 / GND |
| SDA / MOSI | GPIO42 |
| SCL / SCK | GPIO41 |
| DC | GPIO48 |
| RST | GPIO38 |
| CS | GND |

屏幕刷新在低优先级独立任务中运行，SPI 传输不持有驾驶状态锁；驱动初始化或传输报告错误时只停止显示任务。无回读的 SPI 屏幕未接线时可能不会报告错误，需要目视检查。

## 控制与保护

- Wi-Fi WPA2 热点最多连接三台设备；固件同时只签发一个驾驶令牌。
- 页面每 50 ms 发一条 HTTP 指令，单条请求 220 ms 超时，不堆积驾驶请求。
- 固件每 10 ms 检查状态；300 ms 未收到有效指令则撤销令牌并清零输出。
- 令牌失效后，即使迟到的旧指令到达也不能恢复运动；需要重新申请驾驶权。
- 单调递增序号拒绝重复和乱序指令；NaN、无穷及越界值被拒绝，不刷新超时。
- 超时处理位于独立控制任务，网页请求阻塞不影响超时检查。
- STOP 对所有已连热点的控制端开放，撤销驾驶令牌；Wi-Fi 设备离线也保守停车。
- 锁屏、切后台、丢失触点、旋转手机方向都会结束操作，网络丢包时由固件看门狗兜底。
- 平移速度上限 0.12 m/s，旋转上限 0.60 rad/s；默认低速为上限的 50%。斜向平移向量归一化。
- 正常速度变化有斜率限制；全部归零和 STOP 跳过缓变。清零输出不等同于机械上瞬间静止。
- POST 要求自定义请求头且不允许 CORS，阻止普通跨站页面发控制请求。热点密码是访问边界；请勿把此控制器暴露到公网。

## 文件与验证

### iPhone HTTPS 返回 431

若串口出现 `request URI/header too long` 和 `431 Request Header Fields Too Large`，
说明 HTTP 解析器在进入控制接口前拒绝了请求。工程将 `CONFIG_HTTPD_MAX_REQ_HDR_LEN`
从 ESP-IDF 默认 512 字节提高到 4096 字节，同时写入 `sdkconfig.defaults`，供新构建使用。
已有 `sdkconfig` 也必须设置为 4096，单改 defaults 不会覆盖旧值。此设置同时作用于 HTTP、HTTPS 和视频服务。
`-0x0050` 在本工程 mbedTLS 中表示连接被重置；需先消除 431，再检查是否还存在独立的连接超时。
重新构建并烧录后，先关闭视频测试 HTTPS 摇杆，再测试体感，最后开启视频；观察 431 是否消失。
