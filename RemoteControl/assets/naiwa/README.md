# 奶蛙小车表情

参考图下载自 https://milkyfrog.com/assets/milkyfrog-hero.png （2026-09-08）。
`atlas.png` 是使用内置 imagegen、以该图为角色参考生成的项目表情素材，不是官方表情包。
完整生成提示词保存在 `PROMPT.txt`。原参考图为 `reference.png`。

图集 1536×1024，6 列、4 行；相邻两格组成一种表情的 A/B 帧。
依次为睡眠、开心、驾驶、抱心、眩晕、断联、张望、大笑、疲劳、惊讶、鼓腮、点赞。
小车按状态循环两帧：睡眠 1100 ms/帧，眩晕/大笑 350 ms/帧，其他 650 ms/帧。
这些是简短双帧动画，不是视频或完整连续动作。

在工程根目录执行 `python tools/pack_naiwa.py`（需要 Pillow），重新生成
`main/naiwa_assets.c/.h` 和小屏预览 `preview.png` / `preview.gif`。
脚本按经过目视检查的图集间隙裁切，统一缩放，转为全局 256 色 RGB565 调色板，再按每帧 RLE 编码。
更换图集后需重新目视检查裁切行边界；脚本不会自动识别任意图集布局。
24 帧含调色板和索引共 288124 字节，固件不依赖 PNG/GIF 解码器。

`preview.gif` 按统一 650 ms 展示两帧，用于检查所有表情；实际屏幕按上面的不同间隔播放。
底部绿色/粉色条表示连接状态，表情本身不控制电机。
