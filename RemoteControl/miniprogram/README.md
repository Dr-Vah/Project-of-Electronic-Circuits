# 奶蛙驾驶舱

微信开发者工具直接导入本目录，配置有权限的 AppID 后进行真机预览。需配套烧录上级 RemoteControl 的集成版固件。

1. 在线扫码进入小程序，开启蓝牙，点击「连接小车」。
2. 点击「连接画面 Wi-Fi」连接 Omni-Remote（密码 omni2026），再点击「开启画面」。
3. 体感：等待传感器就绪，按住驾驶自动校准。也可切换摇杆，配合左右旋转按钮。
4. 奶蛙卡片实时显示状态，可选择自动或 12 种表情。切换表情／模式／限速先停车。
5. 松手、切后台、失联和正在观看的画面失效会解除操作，需要重新按住。

完整操作、接口、测试和当前实测边界见 [集成说明](../BLE_MIGRATION.md)。
