# 遥控驾驶舱

微信开发者工具导入本目录，配置有权限的 AppID 后编译并真机预览。使用已有 RemoteControl 集成版固件即可，本次横屏改版不需要重新烧录。

1. 页面固定横屏，深灰＋暖橙配色，默认摇杆模式。点击「连接小车」连接蓝牙。
2. 「连接画面」连接 Omni-Remote Wi-Fi（密码 omni2026），再点击「开启画面」。如果切换 Wi-Fi 时离开了小程序，返回后需重新连接蓝牙。
3. 摇杆按住拖动控制前后／横移；左右转向按钮按住旋转，松手停止。速度或模式切换会先停车。
4. 手机体感：按手机顶端（听筒）实际朝向选择「朝左」或「朝右」，横握并保持舒适姿态，点击「校准并开始」。之后无需按住；回到校准姿态停止移动，点击「停止体感」或「立即停止」结束。
5. 左右握持使用相反的 X/Y 轴旋转映射；更换握持方向必须先停止、选择对应方向、重新校准。不要在驾驶中直接把手机调头。页面尺寸变化也会停车。
6. 「连接状态」可查看连接错误、传感器数据、眩晕／疲劳，重新启用传感器、选择是否用罗盘旋转或断开蓝牙。罗盘未就绪时仍可倾斜平移，使用右侧按钮旋转。
7. 「屏幕表情」是文字菜单，可选择自动或 12 种表情；切换会先停车。页面不显示角色图片。
8. 切后台、断联、传感器失效或正在观看的画面中断会停车，不会自动恢复驾驶。

横屏方向映射、校准零点、握持切换／尺寸变化停车，以及蓝牙／摇杆／视频回归已由主机测试覆盖。仍需在手机微信中先架空车轮，核对两种握持下的前后和横移方向；桌面模拟器不能替代真机传感器测试。

完整接口及固件说明见 [集成说明](../BLE_MIGRATION.md)。
