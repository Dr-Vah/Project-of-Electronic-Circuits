# Task2：摄像头巡线与超声绕障

本工程是独立的 ESP-IDF 5.4.x 固件，使用：

- USB UVC 摄像头模拟四路红外完成近场巡线；
- HC-SR04 在 **5 cm** 处触发木板绕行；
- 三轮全向底盘执行 `vx / vy / omega`；
- 摄像头在绕障后重新捕获黑线，不依赖红外传感器。
- 摄像头画面只在板内处理，不启动 Wi-Fi/MJPEG 回传。
- ST7735S显示三个轮子的实测转速和最新超声距离。

## 模块边界

- `camera_uvc`：USB枚举、MJPEG接收和JPEG解码；
- `camera_debug`：保留的调试组件，当前启动流程不启用；
- `line_vision`：四路虚拟红外巡线，并保留多行扫描用于折点预警；
- `ultrasonic`：阻塞式单次测距，不决定运动；
- `course_control`：任务状态机，唯一拥有电机控制权；
- `car_control`：三轮运动学、编码器测速和轮速PID；
- `tft_display`：以5 Hz刷新A/B/D三个轮子的RPM和超声距离；
- `main`：初始化并启动上述模块。

## 关键约束

障碍触发常量 `TASK2_OBSTACLE_TRIGGER_CM` 固定为 `5.0f`。HC-SR04 的
ECHO 为 5 V，接入 ESP32-S3 GPIO47 前必须分压或电平转换。

## 摄像头巡线逻辑

- 只统计画面下方 `72% ~ 96%` 的近场区域，减少远处路线干扰；
- MJPEG 固定以 `1/8` 比例解码；当前 `480 x 320` 摄像头生成
  `60 x 40` 视觉帧，降低 JPEG 解码和 PSRAM 访问压力；
- 取画面中央 `60%` 宽度并均分为四路，每路黑色占比达到 `8%` 即触发；
- 使用固定灰度阈值 `85`，四路巡线结果单帧立即生效；
- 中间两路控制小幅修正，最外路控制转弯；
- 多行线路拟合负责 90°/120° 折点预警；单帧识别即可锁定，随后任一中下扫描行断线便立即转弯；
- 正常巡线时，单帧中四块区域的黑色占比均达到 `70%`，立即识别为终点并停车；普通的低占比 `0xF` 不算终点。
- 视觉结果超过 `200 ms` 即视为过期，旧控制指令最多保持 `250 ms`；
  USB 连续 `500 ms` 没有帧时自动重启视频流。
- 串口每秒输出接收、处理、丢帧帧率，以及 JPEG 平均/最大解码耗时、
  解码失败数和断流数。
- GPIO19/20 由原生 USB Host PHY 直接接管，不在启动前配置为普通 GPIO；
  UVC 枚举成功后串口输出设备地址、视频流索引和可用模式数量。

## ST7735S接线

| 屏幕信号 | ESP32-S3 |
| --- | --- |
| SDA / MOSI | GPIO42 |
| SCL / SCLK | GPIO41 |
| DC | GPIO48 |
| RST | GPIO38 |

显示任务每200 ms读取编码器实测轮速并换算为RPM，同时显示课程控制器最近一次
超声测距；无有效回波时显示 `NO ECHO`。
